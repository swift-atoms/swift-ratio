# swift-ratio

Use this package when you need an exact conversion factor between two typed domains: you want to turn minutes into seconds, element counts into bytes, or bit indices into word locations without rounding and without mixing up which domain a quantity belongs to. Start from `Ratio<From, To>`, which carries a `Rational` factor that maps a `From` quantity to a `To` quantity. When the factor needs no domain tags, use `Rational` from swift-rational directly. When you want approximate floating-point factors per axis, use the swift-scale package instead. The `Bit` trait adds `Bit.Pack<Word>` and `Bit.Pack<Word>.Location`, which split bit counts and bit indices into words using a `Ratio<Word, Bit>`.

## Laws

- Composition multiplies factors. `Ratio<A, B>` composed with `Ratio<B, C>` gives `Ratio<A, C>`, and signs multiply. A ratio composed with its inverse is `Ratio<From, From>.identity`. Composition is exact and is not limited to machine integer widths.
- Zero is canonical. A zero ratio has `polarity == nil` and equals `.zero`, whichever polarity it was built with. Composing with zero gives `.zero`, and inverting zero fails with `zeroFactor`.
- Scaling never rounds. Applying a ratio to an integral quantity (`Int128`, `Cardinal`, `Difference` or `Ordinal`) fails with `inexact` if the result is not an integer, and with `overflow` if the result does not fit the output type. Applying a ratio to a `Rational` is always exact. `intValue()` follows the same rule: a non-integer gives `inexact`, and a value outside `Int` gives `unrepresentable`.
- Unsigned quantities (`Cardinal`, `Ordinal`) accept any factor when the input is zero, and the result is zero. A negative factor applied to a nonzero unsigned quantity fails with `negativeFactor`. Signed `Difference` quantities take the sign of the product, and a zero result is normalized to zero.
- Division by a ratio (`quotient(dividing:)`, `quotientAndRemainder(dividing:)`) takes a `To` quantity and returns a `From` quotient and a `To` remainder. The factor must be a positive integer: zero fails with `zeroFactor`, a negative factor with `negativeFactor`, and a fraction with `nonintegralFactor`. Signed division is Euclidean, so the remainder is never negative (−61 seconds ÷ 60 gives −2 minutes with a remainder of 59 seconds).
- The `*` operators trap where `multiply.exact(by:)` throws. Use `multiply.exact(by:)` whenever the input can overflow, be inexact, or meet a negative factor.
- Each `Ratio<From, To>.Error` belongs to its own pair of domains: `Ratio<A, B>.Error` and `Ratio<B, A>.Error` are different types. The error is `Sendable` even when the domain tags are not.
- `Ratio<T, Memory>.stride` is `MemoryLayout<T>.stride`, which includes padding.
- `Bit.Pack<Word>` rounds the word count up. `bits.unused` is the number of bits left over in the last, partial word, and is 0 when the bit count is a whole number of words. `Bit.Pack<Word>.Location` places a bit index at word `index / bitsPerWord`, at bit `index % bitsPerWord` within that word, with `mask == 1 << bit`. `index(bitsPerWord:)` reverses this exactly. Both trap if the ratio is not a positive integer that fits in `UInt`.
